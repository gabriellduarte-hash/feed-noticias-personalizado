# Versões exatas de tudo o que o coletor instala, incluindo as dependências
# das dependências (auditoria de 20/10). Sem isso, cada execução do GitHub
# Actions instalava a versão mais nova de tudo: um pacote comprometido no
# PyPI rodaria lá com a senha do banco no ambiente.
#
# Os workflows instalam com: pip install -r requirements-nlp.txt -c constraints.txt
# (requirements*.txt dizem O QUE instalar; este arquivo, QUAL versão).
#
# Pra atualizar (de dentro da pasta do projeto, com o uv instalado):
#   uv pip compile requirements-nlp.txt --python-version 3.12 \
#     --python-platform x86_64-manylinux_2_28 --exclude-newer AAAA-MM-DD \
#     --no-header --no-annotate | grep -v "@ https" > /tmp/novas.txt
# e troque as linhas abaixo pelas de /tmp/novas.txt. O --exclude-newer com
# uma data de 2 semanas atrás evita versões recém-publicadas (é nelas que
# um pacote comprometido costuma aparecer, antes de ser descoberto).
# Os modelos do spaCy ficam de fora: já vão com versão fixa no
# requirements-nlp.txt.
